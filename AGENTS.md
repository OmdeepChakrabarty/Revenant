## 3. Canonical Data & API Contracts

Keep backend Pydantic models and frontend TypeScript types **100% identical** (camelCase everywhere). The backend has NO database. All data lives in the browser (`localStorage`, append-only), and the relevant documents and links are sent to `/ask` in the request body.

### Browser Store Schema (`frontend/src/xanadu.ts`, key `xanadu:v1` in `localStorage`)
* `documents`: `{ docId, title, latestVersion, createdAt, status: "active" | "removed", useInQuestions: boolean }[]` — `status` defaults to `"active"`; `"removed"` is a soft remove (hidden from graph, Reader and `/ask`, restorable). `useInQuestions: false` excludes a still-active document from `/ask` (dimmed in the graph). Both fields are normalized on read for stores persisted before they existed.
* `documentVersions` (APPEND-ONLY): `{ docVersionId, docId, version, content, contentHash, parentVersionId, createdAt }[]`
* `spanLinks`: `{ linkId, linkType, fromDocVersionId, fromStart, fromEnd, toDocVersionId, toStart, toEnd, exactQuote, prefix, suffix }[]`
* `aiAnswers`: `{ answerId, question, fullText, traversal: { step, fromDocId, toDocId, spanId }[], sentences: AnswerSentenceClaim[], createdAt }[]`

Seed data lives as exported constants in `xanadu.ts` (no JSON files): `SEED_DOCS` (5–6 documents, about 150 words each, quoting each other), `SEED_LINKS`, and `DEMO_ANSWER` (one recorded `AIAnswerRecord` with its hop events). Wrap every `localStorage` read/write in try/catch, and fall back to the seed constants when storage is empty or unavailable.

### Core JSON Shapes (`frontend/src/xanadu.ts` & `backend/app.py`)
```typescript
export interface SpanAddress {
  spanId: string;        // "${docId}@v${version}:${start}-${end}"
  docId: string;
  docVersionId: string;  // "${docId}@v${version}"
  version: number;
  start: number;         // 0-based inclusive
  end: number;           // 0-based exclusive
  exact: string;
  prefix: string;        // 32 chars before start
  suffix: string;        // 32 chars after end
}

export interface AnswerSentenceClaim {
  sentenceIndex: number;
  text: string;
  answerStart: number;
  answerEnd: number;
  citedSpans: SpanAddress[];
  groundingStatus: "supported" | "unsupported"; // "unsupported" = Ghost Claim
  hallucinationConfidence: number;              // simple mode: 0.0 = supported, 1.0 = unsupported
  stalenessStatus: "fresh" | "outdated";
}
```

### API Endpoints (`backend/app.py`) — only two
1. `POST /ask` — Body: `{ "question": string, "documents": [{ "docId": string, "title": string, "version": number, "content": string }], "links": [<spanLinks rows>] }` (send the LATEST version of each document only). Responds with Server-Sent Events (`text/event-stream`) using FastAPI `StreamingResponse`:
   * `event: hop` with `{"step": 1, "fromDocId": "a", "toDocId": "b", "spanId": "b@v1:10-80"}` for each link traversed.
   * `event: answer` with the final verified `AIAnswerRecord` JSON (the server generates `answerId`; the browser saves it to `aiAnswers`).
   * `event: error` with `{"message": string}` on failure (the frontend then replays the Demo answer).

   The client MUST read this with `fetch` + `ReadableStream`. Browser `EventSource` cannot send POST. The frontend reads the backend base URL from `import.meta.env.VITE_API_URL` (default `http://localhost:8000`).
2. `GET /health` — returns `{"ok": true}`.

The FastAPI instance MUST be named `app` in `backend/app.py` so Vercel auto-detects it. The document list, edits, graph (`nodes`/`links` for `ForceGraph2D`), saved answers and staleness are all computed in the browser. Do NOT add other endpoints.

Environment variables: `LLM_API_KEY`, `LLM_MODEL`, `LLM_MODE=live|fake`, `GHOST_MODE=simple`, `ALLOWED_ORIGIN`. Call the LLM with `httpx` against a free-tier provider's REST API (default: Google Gemini); no heavy SDKs.

## 4. Approved Libraries & Exact Integration Points

Always use these vetted libraries—do **not** substitute heavy frameworks or copyleft packages:

* **Feature 1 — Stale-Answer Detection (`frontend/src/xanadu.ts`):**
  * Package: [`diff-match-patch-typescript`](https://github.com/nonoroazoro/diff-match-patch-typescript) (Apache-2.0).
  * Logic: Run `diff_main(oldContent, newContent)` and translate offsets via `diff_xIndex(diffs, start)` / `diff_xIndex(diffs, end)`. If `newContent.slice(newStart, newEnd) !== span.exact`, run a fuzzy `TextQuoteSelector` (`{exact, prefix, suffix}`) fallback adapted from [`hypothesis/client`](https://github.com/hypothesis/client) (`src/annotator/anchoring/`). If still mutated or missing, flag the sentence and answer as `"outdated"`.
* **Feature 2 — Ghost Claims (`backend/provenance.py`):**
  * Prompt: Adapt [`patterns/agents/prompts/citations_agent.md`](https://github.com/anthropics/anthropic-cookbook/blob/main/patterns/agents/prompts/citations_agent.md) from [`anthropics/claude-cookbooks`](https://github.com/anthropics/claude-cookbooks) (MIT). Wrap every retrieved span as `[SPAN docId@v:start-end]...[/SPAN]` and instruct the LLM to tag claims with `<cite span="docId@v:start-end">...</cite>`.
  * Verifier (`GHOST_MODE=simple`, the ONLY mode in this build): split the answer into sentences. A sentence is `"supported"` only if (a) it has at least one `<cite span="...">` whose `spanId` was in the retrieved set, (b) the cited span's `exact` text appears verbatim in the source document content, and (c) at least 30% of the sentence's content words (lowercased, stop-words removed; constant `MIN_OVERLAP = 0.3`) appear in the cited text. Otherwise mark it `"unsupported"` (Ghost Claim). Set `hallucinationConfidence` to `0.0` when supported and `1.0` when unsupported.
  * Rule: Drop any `<cite>` referencing an unretrieved `spanId`. Do NOT install `lettucedetect`, `torch`, or `transformers` (Vercel bundle size).
* **Feature 4 — Animated Link Traversal & Span Bridges:**
  * Macro Graph (`frontend/src/GraphView.tsx`): [`react-force-graph-2d`](https://github.com/vasturiano/react-force-graph) (MIT). Highlight the active node with a glowing halo in `nodeCanvasObject` and trigger `fgRef.current.emitParticle(link)` on every incoming SSE `hop` event.
  * Micro Span Bridges (`frontend/src/ReaderAndProof.tsx`): [`react-xarrows`](https://github.com/Eliav2/react-xarrows) (MIT). Wrap panes in `<Xwrapper>`, assign `id="claim-{i}"` to answer sentences and `id={spanId}` to source `<mark>` spans, and draw `<Xarrow start={claimId} end={spanId} animateDrawing={0.3} />`. **Important:** Call `useXarrow()` inside a `requestAnimationFrame`-throttled `onScroll` handler so lines stay locked while scrolling.
* **Bonus — Obsidian Importer (`frontend/src/xanadu.ts`), ONLY after Steps 1–5 pass:**
  * Adapt `wikilinkRegex` (`[[Note]]`, `![[Embed]]`, `#^block-id`) from [`jackyzha0/quartz`](https://github.com/jackyzha0/quartz) (`quartz/plugins/transformers/ofm.ts`, MIT) to parse uploaded Markdown files into `spanLinks` in the browser.
